# Validácia znalostí v CI

Pre-commit hook kontroluje, čo každý commitne. CI job zachytí všetko ostatné: commity s `--no-verify`, stroje bez kontextu a záznamy, ktorých `paths` po refaktoringu prestali niečomu zodpovedať.

## GitHub Actions

```yaml
# .github/workflows/knowledge.yml
name: knowledge
on:
  pull_request:
    paths: [".ai/**", "docs/adr/**"]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install kontext
        run: curl -fsSL https://raw.githubusercontent.com/SemanS/kontext/main/scripts/install.sh | sh
      - name: Validate entries and scan for secrets
        run: ~/.local/bin/kontext check
```

`kontext check` skončí so stavom 1 pri chybách (chýbajúce titulky, neznáme druhy, duplicitné ID, tajné údaje s vysokou istotou) a varovania vypíše bez zlyhania.

Pre reprodukovateľné buildy zafixuj verziu:

```yaml
        run: curl -fsSL https://raw.githubusercontent.com/SemanS/kontext/main/scripts/install.sh | KONTEXT_VERSION=v0.1.0 sh
```

## Iné CI systémy

Funguje akýkoľvek runner s gitom:

```sh
curl -fsSL https://raw.githubusercontent.com/SemanS/kontext/main/scripts/install.sh | sh
~/.local/bin/kontext check
```

## Užitočné doplnky

- `kontext log --json` vytvorí strojovo čitateľnú časovú os rozhodnutí, napr. pre dokumentačný web.
- `kontext check` skenuje znalosti aj na tajné údaje; lokálne nastav `secrets.scan = "staged"`, ak chceš, aby hook skenoval každý stagnutý súbor.
